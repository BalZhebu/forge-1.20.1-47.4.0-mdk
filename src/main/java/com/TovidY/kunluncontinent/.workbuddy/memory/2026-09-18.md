# 2026-09-18 技能特效体系全面重构

## 目标
把 baseskillist 下 4 武魂 × 9 魂技（共 36 个技能类）的粒子特效全部重做，
要求「数学函数驱动、圆环/多边形/魔法阵打散封装、自定义高度、控制力强、华丽」。
数值 / 消耗 / 冷却 / 伤害逻辑一律不动，只替换视觉层。第 7 魂技只做轻量美化。

## 关键实现要点（踩坑记录）
- **精确落点靠 `count = 0`**：`ServerLevel.sendParticles(type, x,y,z, 0, vx,vy,vz, 1.0)` 会在
  客户端**精确坐标**生成 1 个粒子，并把 `(vx,vy,vz) * speed` 当作初速度。
  `count > 0` 会被高斯噪声打散，只适合做「体积感」（见 `bloom`）。
- **本版本（1.20.1 Forge 47.4.0）不存在 `ParticleTypes.DUST_PLUME`**（那是 1.21 的）。
  岩土类尘土请用 `WHITE_ASH` / `ASH` / `CAMPFIRE_COSY_SMOKE`。
- 不要用 `look.cross(new Vec3(0,1,0)).normalize()` 求横向单位向量 —— 垂直视角时叉积为
  零向量、normalize 出 NaN。统一改用 `ParticleFx.ortho(dir)`。
- 作用域坑：如果在 `if (fx != null) { ... }` 块内声明 `double rot` / `Vec3 origin`，
  块外还要用就会编译失败。凡是要复用的变量都提到 `if` 之前声明。
