# 2026-10-02 NPC 亡语 + NPC 魂骨掉落

## 需求
1. **玩家击杀 NPC 时** NPC 释放亡语（用户给了 "不，我不甘心！"、"怎么可能！！"）
2. NPC 有极低概率自带魂骨；击杀有较大概率掉出来
3. 等级越高魂骨越强；**95 级以上才可能掉百万年**，最高百万年
4. 需要调试指令

## 关键发现：NPC 和玩家共用同一个属性类
`PlayerNpcEntity.soulCapability` 就是 `PlayerAttributeCapability`，
所以它天然带 7 个魂骨槽 `hunguInventory` + `boneOnlyStats` ——
"给 NPC 装魂骨"不需要任何适配层，直接塞槽 + 汇总即可。

## 魂骨系统分析结论
- 魂骨 = `BoneItem` + `ItemAttributeCapability`（NBT key `shanhaiitematuble`）
- `toUpdateNianxian(int)` 按年限档位算 11 项属性（和魂兽魂骨完全同一套）
- 玩家侧汇总在 `PlayerAttributeCapability.refreshBoneAttributes(Player)`，
  **末尾会 `SynsAPI.synsPlayerAttribute(player)` 发网络包** → NPC 不能直接调

## 实现
### 新增
- `entity/playernpc/NpcBoneGenerator` — 生成/生效/掉落唯一实现处
- `entity/playernpc/NpcDeathWhisper` — 亡语文案池（LOW/MID/HIGH 按等级分段）+ ActionBar 播报
- `command/tovid/NpcDebugCommand` — `/kunluncontinent npcdebug`

### 修改
- `PlayerAttributeCapability`：`getAttrValueByKey` 改 **public static**，
  新增 `collectBoneAttributes(cap)` **public static**（只汇总不发包），
  `refreshBoneAttributes(Player)` 改为调它 + 发包。玩家/NPC 共用，口径不会漂移。
- `PlayerNpcEntity`：
  - `recalculateNpcStats()` 改为裸值 + `boneOnlyStats`（生命/攻击）
  - 新增 `applyVanillaAttributes()` + 7 个 `boneXxx` 字段（防御/暴击/闪避走自定义公式，无原版实例）
  - `refreshNpcAttributes()` 改为直接调 `recalculateNpcStats()`（原来是一份重复旧拷贝）
  - `die(DamageSource)` 加玩家击杀结算：亡语 + 魂骨掉落
  - 新增 `resolveKiller(cause)` / `cleanDisplayName()`
  - `finalizeSpawn` 加 `NpcBoneGenerator.tryEquipBone`

## 数值（用户要求：概率极低但"带魂骨的 NPC 打掉基本必掉"）
- 年限**档位对齐**（不是连续随机，避免"高等级掉低年限"）：
  1~49→10~99年 / 50~69→百 / 70~84→千 / 85~94→万 / **95~99→十万（95 硬门槛）** / 100+→十万~百万
- NPC 自带概率：1~59 级 1/50000 … 95~99 级 1/6000、100 级 1/5000
- 击杀掉率：55%（低）→ 90%（100 级）
- 综合 0.00055%~0.9%
- 词条数也随等级：3 条（低级）~ 10 条（满级），±1 抖动

## 踩的坑
- `ItemAttribute` 的 getter 叫 **`getGongji/getFangyu`**，不是魂兽那套
  `getWugong/getWufang` —— 我一开始按魂兽命名写全错了。已抽公共静态方法解决。
- 1.20.1 **没有 `SoundEvents.WRAITH_AMBIENT`**，改用 `ENDERMAN_SCREAM`。
- `getLastHuntByMob()` 在 1.20.1 返回类型已是 `LivingEntity`，
  写 `last instanceof LivingEntity` 会报"模式类型是表达式类型的子类型"。
- 指令里取玩家用 `source.getPlayer()`，**不能用 `getPlayerOrException()`**（抛检查异常）。
