# 2026-10-02（第三段）属性点面板 + 老存档返还

用户需求：属性面板右侧插第二个新面板（属性点面板）；每升 1 级得 1 点；
面板先只显示当前点数；老存档要返还但**不能重复发**（退出重进不能再发一次）。

## 改动
- `PlayerAttributeCapability`：`attributePoints` + `pointsGrantedLevel`
  （NBT 键 `AttributePoints` / `PointsGrantedLevel`；后者默认 `Integer.MIN_VALUE` 表示"从未发放"）。
- 新增 `AttributePoints`（发点工具类，两个入口）：
  - `grantOnLogin`：老存档首次（`pointsGrantedLevel == MIN_VALUE`）按当前等级全额补发并记账；
    之后只补 `dengji - grantedLevel` 的差额。**幂等，不会重复发。**
  - `grantOnLevelUp`：新等级 > 已记账等级才发，发完把记账推到新等级。
- 挂点位置（两条升级路径都挂，漏一条就少发）：
  - `PlayerUpgradeSystem.processSuccessfulUpgrade`（普通升级）
  - `PlayerUpgradeSystem.processAwakening`（觉醒，`applyGrowthAndBonus` 之后）
  - `PlayerUpgradeEventListener.onPlayerLoggedIn`（登录时补发，在 triggerUpgradeCheck **之前**）
- 新面板 `screen/attribute/point/{PointMenu,PointScreen}.java`：
  空槽菜单 + 复用 KunlunGuiHelper 面板；中间显示大号点数 + 当前等级 + "每级 1 点"。
  `PointScreen implements AttributeTabs.Host`。
- 注册：`ModMenuTypes.POINT_MENU` + `MenuScreens.register(POINT_MENU, PointScreen::new)`；
  `AttributeTabs.PAGE_POINT = 5`，在 `ensureRegistered()` 里**插到 PAGE_ATTRIBUTE 之后**（显示第 2 位）。
- 图标占位：`ModItems.POINT_BUTTON` 加进 `KLBUTTON` 集合（datagen 自动 basicItem），
  贴图直接复制 `shenkao_button.png` 当占位（用户同意图标先随便改）。

## 关键坑
- `LanguageProvider.add(key, value)` 内部是 `data.put`，**重复键直接抛
  `IllegalStateException: Duplicate translation key`**，datagen 整轮失败。
  用户已自己在文件第 40-43 行加过 fly_crash_1~4，我又加了一份 → 报错。
  **加语言键前先 grep 该键是否已存在。**
- `AbstractContainerMenu` **没有** `getDisplayName()`（那是 `MenuProvider` 的），
  写 `@Override` 直接编译失败。`quickMoveStack` 也不是父类方法。
- `GuiGraphics.drawCenteredString` 只有 4 参版本，没有带 `boolean shadow` 的重载；
  要阴影就自己 `drawString(font, s, x - font.width(s)/2, y, color, true)`。
