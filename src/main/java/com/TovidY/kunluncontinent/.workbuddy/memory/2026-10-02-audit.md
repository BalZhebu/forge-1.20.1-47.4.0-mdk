# 2026-10-02（第五段）属性生效全审计 + 修 3 个 BUG

用户要求逐个检查 11 种属性是否真的生效。

## 审计结论（结算全在 `CombatEventHandler.onLivingHurt`）
| 属性 | 生效点 | 结论 |
|---|---|---|
| 攻击力 gongji | `(gongji + event.getAmount()) × 减伤` | 正常 |
| 防御力 fangyu | `reductionFactor = 100/(100+有效防御)` | 正常 |
| 暴击率 baojilv | `暴击率 - 抗暴` 判定 | 正常 |
| 暴击伤害 baojishanghai | `baseDamage × (暴伤/100)` | 正常 |
| 生命恢复 shengminghuifu | `PWPlayerTickEvent.updatePlayerHealthRegen` 每 100 tick | 正常 |
| 吸血 xixue | `handleLifesteal` = `xixue/(xixue+100) × 伤害` | 正常 |
| 闪避 shanbi | `(shanbi-mingzhong)/(diff+100)` 免疫 | 正常 |
| 命中 mingzhong | 闪避的克制项 | 正常 |
| 物穿 wuchuan | `max(0, fangyu - wuchuan)` | 正常 |
| 抗暴 kangbao | 从暴击率里减 | 正常 |
| 生命/精神/经验/等级 | — | 正常 |

曲线均为 `x/(x+100)` 型递减趋上限，无失控。生命恢复封顶每 5 秒 6% 最大血（恢复≥30 即满）。

## 修掉的 3 个 BUG
1. **`ModAttributeAPI.getXixue` 读错药水方法**：循环里调的是 `potionAttr.getWugong()`（攻击力），
   吸血类药水会错误地加攻击力。已改为 `getXixue()`。
2. **`getShanbi` 完全不读药水**：原代码是空 for 循环（只有注释"可以添加对药水效果的处理"），
   闪避药水一律无效。已补 `potionAttr.getShanbi()`。
3. **`CombatEventHandler.getFlyingDamageMultiplier` 用错等级**：
   读的是 `player.experienceLevel`（**原版经验等级**，本项目几乎不用），
   飞行减伤永远走 `<70 → 0.6` 分支，70/90 级双档形同虚设。已改为 `ModAttributeAPI.getDengji(player)`。

## 注意（未改）
`ModAttributeAPI.getEffectiveFangyu` 注释写"考虑破甲效果"但只是转发 `getFangyu`，
实际破甲 debuff 已在 `getFangyu` 内 `*= 0.7f` 实现了 —— **功能是生效的，只是方法名有误导**。
