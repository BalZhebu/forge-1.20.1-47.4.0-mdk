- 结构：独立虚空维度 `TOWER_REALM`，塔沿 X 轴每 300 格一座（塔 id = round(x/300)），

- 战斗层：`TowerSpawnerEngine` 按 FloorData 刷怪（MobAttribute 年限→血量），怪物挂

  玩家死亡/超时/越界/登出/换维度/点石印逃跑 → 失败（当前层 -1，即重打当前层）。
- 限制：`TowerRestrictionHandler`（禁破坏/放置/丢物、越界判定 distanceSq>18² 或 Y<50、
  每 tick 限时倒计时 PacketSyncTowerTimer 同步 HUD）。

## KunlunGuiHelper 全面美化 + 动画化（只改这一个文件，6 个面板同步受益）

  每个组件自持 `lastMillis`，renderWidget 里用 `Util.getMillis()` 算 dt（上限 clamp 0.1s 防卡帧跳变）。
- `lerpColor(from, to, t)`：逐通道颜色插值（含 alpha）。
- `easeOutCubic`、`withAlpha(baseAlpha, t, rgb)`。

### 各组件动画
- **面板背景**：纯色 → 纵向渐变（PANEL_TOP→BOTTOM）+ 顶部内侧金色反光线；
  新增**金边流光**（12 段正弦亮度、周期 5.2s，顶边正向底边反向，`drawBorderShine`）；
  四角装饰随时间**呼吸**（sin 脉动 lerpColor）。
- **槽位**：内侧向下渐暗增强凹陷感；isHighlight 槽边框金色缓慢呼吸。
- **HandDrawnButton**：悬停量 hoverAnim 0~1 插值底色/边框/文字色；
  左侧金饰条随悬停从中间长出（fillGradient 渐隐）；悬停底部泛金晕 + 上半区提亮；
  **按下回弹**：onPress 置 pressAnim=1，renderWidget 里衰减，以中心为原点 `pose().scale(1 - 0.05*pressAnim)`。
- **KunlunTabButton**：三态（未选/悬停/选中）连续插值，切页签颜色是"流"过去的；
  选中金条从中间向两边生长（easeOutCubic）；图标选中时上浮 1px + 身后淡金光晕浮现。
- **HandDrawnEditBox**：focusAnim 插值，聚焦时边框灰→金平滑过渡、底色微亮。

### 兼容性

# （第四件）词条等级系统（1~10 级，罗马数字显示）

用户需求：词条分 1~10 级，显示为 词条I~词条X，等级可被层数生物自定义。
等级强度曲线（用户拍板）：1级=原始数值，每级 +10%，即 levelMultiplier = 1 + (lv-1)*0.1，10级=190%。

### 机制
- 规格写法：词条名后接罗马数字（可带空格），如 狂暴 III / 壁垒X；不带后缀 = 1 级（老配置全兼容）。
- 解析：TowerSkillPool.parseSpec(raw) 返回 record ParsedSpec(name, level)，
  正则 ^(.+?)\s*([IVX]{1,4})$ 且罗马段必须在合法表内（防止普通词条名被误拆）。
- 注入：ITowerModifier 新增 default apply(mob, level)（默认退回 apply(mob)，等级不敏感词条零改动）；
  统一曲线 TowerSkillPool.levelMultiplier(int)。
- 随机词条恒为 1 级；去重按解析后的基础名。

### 各词条等级映射（1级 = 原值）
- 壁垒/浑厚：加成比例 × levelMultiplier（壁垒 60%→114%，浑厚 65%→124%）
- 狂暴：物攻加成 0.5 × levelMultiplier（10级 +95%）；恢复：治疗 20% × levelMultiplier（10级 38%）
- 瞬移：冷却 10s ÷ levelMultiplier（10级约 5.3s，下限 4s）
- 泥沼：缓慢 amp=min(level+1,4)、时长 6s×mult；恐惧：三种负面时长 ×mult
- 迅速：离散，药水等级=min(level,4)（1级=速度II 不变，上限速度V）
- 不死/濒死/荆棘/禁空/免伤：boolean 照旧，另存 Skill_XXX_Level NBT 备用（消费端未动）
- 5 个 Goal 构造器加 int level 参数（保留 1 参旧构造器），触发飘字带等级显示
  （ShieldActiveSkillNotify 3 参重载，getTriggerText(level) 把名字换成 名字+罗马数字）

### 关卡表
第 15~34 层指定词条按层爬等级：16~22 层 II 级为主，25~28 层 III 级出现，29~33 层 III~IV 级，
34 层顶配 狂暴IV/濒死III。0~13 层不动（全 1 级）。名字挂件显示如 狂暴III（金色=主动）。

## 校验
第一次编译 3 个错误（parseSpec 的 String[] 混装 int）→ 改成 record ParsedSpec 后，
`gradlew.bat compileJava --offline` → BUILD SUCCESSFUL。

# （第十二件）与极简血量（Neat）自动共存：塔怪原版名牌按需取消
用户无法改 Neat 代码，要求我们模组自己解决"塔怪名字与 Neat 血条牌重叠"。
源码确认（D:\xiangmu\forge-1.20.1-47.4.0-mdk\极简血量源码，modid="neat"）：
- Neat 血条牌画在 bbHeight+0.6（height_above_mob），牌顶**会原样画完整自定义名**（show_entity_name）；
- 原版名牌在 bbHeight+0.5 → 同位置叠字；
- Neat 有 mixin 能隐藏原版名牌，但需要玩家自己开 disable_name_tag 配置。

### 实现（TowerNamePlateCompat.java，纯事件无需 mixin）
- `RenderNameTagEvent`：装了 Neat（ModList.get().isLoaded("neat")）且
  名字含 "[词条: "（塔怪标识）且距玩家 ≤24 格（Neat 默认 max_distance，出范围 Neat 不画牌、
  原版名牌照常兜底）→ 取消原版名牌，让 Neat 牌独占显示（牌顶名字含年限+词条，颜色码生效）；
- 没装 Neat 的玩家零影响（原版名牌路径）；NPC / 其它命名生物不受影响（名字无词条标签）。
- 坑：1.20.1 的 `ModList.isLoaded` 是**实例方法**（要 `ModList.get().isLoaded`）；
  编译时沙箱偶发拦截 .gradle daemon 锁，重试即可。

## 校验（第十二件后）
`gradlew.bat compileJava --offline` → BUILD SUCCESSFUL。

# （第十三件）放弃 Neat 兼容，词条改为名牌第二行（常显）
用户实测 TowerNamePlateCompat 导致崩溃，要求别管 Neat：改回原先显示 + 换行。
（\n 在原版名牌里会渲染成 ␤ 字形，名牌单行无真换行 → 换行只能自绘第二行。）

### 最终结构
- `monsterJoin`：名字恢复 "怪物名-----X年"（不拼词条），塔怪 setCustomNameVisible(true) 常显
  （用户自己手写的 "\n" 版本已清除）。
- `MobAttributeCapability` 新增 `towerSkillsTag` 字段（String，序列化进 NBT）——
  词条标签随 **现有 SPacketEntityAttribute / monsterHashMapCapability 同步链路**到客户端，
  不需要新网络包、不依赖 persistentData（persistentData 不同步）。
- `TowerSkillPool.applySkills`：apply(mob, level) 注入后
  `cap.setTowerSkillsTag("§6狂暴III §e壁垒...")`。
- 新客户端渲染器 `tower/skill/client/TowerSkillTagRenderer.java`：
  `RenderLevelStageEvent`(AFTER_PARTICLES) 遍历 entitiesForRendering，
  capability.towerSkillsTag 非空者在**原版名牌正下方**画词条行：
  锚点 = bbHeight + 0.5 - 行数×0.225（clamp ≥ bbHeight+0.02），
  行画法 font_y=(行数-1-行序)×9（第 0 行最上），64 格上限、插值定位、
  公告板、0.025 缩放、深色衬底、NORMAL 模式（不穿墙）。
- 原版名牌 = 第一行（名字+年限），自绘 = 第二行（词条）——即"年后面换行"的落地。
- Neat 无需任何配置：它的血条牌照常画在 bbHeight+0.6（如果用户还开 disable_name_tag
  会有叠加，但用户已放弃 Neat 路线）。

# （第十件）指向判定修复：不用 crosshairPickEntity，自己算视线夹角
用户反馈：主动词条释放时飘字有，但瞄准时词条牌还是不显示。
根因：`mc.crosshairPickEntity` 只在原版 ~4.5 格拾取距离内才有值，打怪基本都在 5 格开外。
修法：`findAimedMob(mc)` 遍历 `mc.level.entitiesForRendering()` 里带"词条"的生物，
按视线夹角（acos(look·toMob)）取最小且在容差内的一只：
容差 = max(2.5°, atan2(半宽×0.7, 距离))——远距离瞄窄一点、近距离好指；32 格上限；
贴脸（<0.5 格）必中；松开后 0.5s 内牌子保留防滑脱闪烁（lastAimedId/Millis）。

## 校验
`gradlew.bat compileJava --offline` → BUILD SUCCESSFUL。
